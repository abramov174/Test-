# Сестринское дело — офлайн-поиск

385 вопросов и ответов из тренажёра.

## Включение сайта
Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Установка на iPhone
Откройте сайт в Safari → Поделиться → На экран Домой. Затем откройте новую иконку с интернетом и дождитесь «Все 385 вопросов сохранены». Проверьте работу в авиарежиме. Не очищайте данные приложения.

Ответы из исходного файла, медицинская актуальность не проверялась.
