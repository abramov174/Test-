# Сестринское дело — офлайн-поиск

385 вопросов и ответов из тренажёра. После установки работает без сети.

## iPhone
Откройте сайт в Safari → Поделиться → На экран Домой. Откройте новую иконку с включённым интернетом. Дождитесь «Все 385 вопросов сохранены», затем проверьте в авиарежиме. Не очищайте данные приложения.

## Размещение
Settings → Pages → Deploy from a branch → main → / (root) → Save.

Ответы перенесены из исходного файла без проверки медицинской актуальности.
